General Communication
--

* When writing natural language output, use concise and neutral phrasing.

Version Control
--

* Do not add `Co-authored-by:` in commit messages.
* When contributing fixes following review, squash fixes back into the commits
  that need fixing.  A PR must not contain known-incorrect commits followed by
  fixups to those commits.
